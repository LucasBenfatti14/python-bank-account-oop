## 🚀 Sobre o projeto

Este projeto consiste em uma simulação de uma conta bancária desenvolvida em Python utilizando os principais conceitos de Programação Orientada a Objetos.

A aplicação implementa operações básicas de uma conta bancária, como depósitos, saques e alteração do titular, protegendo operações sensíveis através da validação de senha.

A senha do usuário é armazenada utilizando o algoritmo de hashing SHA-256, simulando uma prática utilizada em aplicações reais para evitar o armazenamento de senhas em texto puro.

Durante o desenvolvimento foram aplicados conceitos fundamentais de POO, como encapsulamento, propriedades (`@property`), validação de dados, tratamento de exceções e organização do código.

Trata-se de um projeto **100% autoral**, desenvolvido com o objetivo de praticar Programação Orientada a Objetos e boas práticas de desenvolvimento em Python.
